# IP Fragmentation Visual Learning Kit

An interactive educational tool designed for networking and cybersecurity students to master IPv4 Maximum Transmission Unit (MTU), 8-byte alignment rules, Fragment Offsets, and More Fragments (MF) flags.

## 🚀 How to Run Locally
1. Save all four project files (`index.html`, `styles.css`, `script.js`, `README.md`) in the same folder.
2. Double-click `index.html` to open and run the application in any modern web browser.

## 🌐 Publishing to GitHub Pages
1. Push all 4 files to a public GitHub repository.
2. Go to **Repository Settings** > **Pages**.
3. Under **Branch**, select `main` and `/ (root)`.
4. Click **Save** to publish your live website!
