Avoid These Exam Mistakes

Learn how to spot and avoid the 6 most common student mistakes on exams.

Pitfall 1

Forgetting to Subtract IP Header from MTU

❌ Wrong: Setting max payload equal to MTU (e.g., MTU 1500 → payload 1500).

✔️ Correct: Max Payload = MTU − IP Header Length (1500 − 20 = 1480 bytes).

Pitfall 2

Failing to Round Non-Final Payloads to Multiples of 8

❌ Wrong: Using non-final fragment payloads like 1482 bytes.

✔️ Correct: Non-final payloads must be multiples of 8 bytes: floor(1482 / 8) × 8 = 1472 bytes.

Pitfall 3

Treating Fragment Offset as a Byte Count

❌ Wrong: Setting Fragment Offset to 1480 for fragment 2.

✔️ Correct: Offset is in 8-byte units: Prior Payload Bytes / 8 (1480 / 8 = 185).

Pitfall 4

Setting MF = 0 on Non-Final Fragments

❌ Wrong: Thinking MF = 0 means "this is a fragment".

✔️ Correct: MF = 1 means "More Fragments follow". Only the final fragment has MF = 0.

Pitfall 5

Confusing Total Length with Payload Length

❌ Wrong: Calculating fragment offset using total length instead of payload bytes.

✔️ Correct: Fragment Offset tracks original payload position excluding IP headers.

Pitfall 6

Forgetting That Every Fragment Has an IP Header

❌ Wrong: Summing fragment payloads and ignoring header overhead.

✔️ Correct: Every single fragment gets its own IPv4 header (usually 20 bytes).

Quick Revision Sheet: IPv4 Fragmentation

🔑 Essential Definitions

  • MTU (Maximum Transmission Unit): Largest total packet size a link can carry without fragmentation.
  • Fragment Offset: Measures position of fragment payload in 8-byte blocks.
  • MF Flag (More Fragments): 1 = More follow; 0 = Final fragment.
  • DF Flag (Don't Fragment): 1 = Drops packet if MTU is exceeded and sends ICMP error.

📐 Calculation Formulas

  • Original Payload: Total Length − Header Length
  • Max Fragment Payload: floor((MTU − Header) / 8) × 8
  • Fragment Offset: Prior Payload Bytes / 8
  • Fragment Total Length: Header Length + Fragment Payload

📋 Standard Reference Example (4000B Datagram, 20B Header, 1500B MTU)
